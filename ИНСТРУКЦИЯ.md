# Как пользоваться: правки в Figma руками Claude

Вы пишете Claude задачу словами: «поменяй заголовок», «собери состояния поля», «пойдем по комментариям». Он сам
открывает нужный фрейм, правит слои и проверяет результат по картинке. Все происходит прямо в вашем файле Figma, пока он
у вас открыт.

Нужен маленький плагин в Figma — «мост». Он передает Claude доступ к открытому файлу.

---

## 1. Что поставить (один раз)

| Что | Где взять | Как проверить |
|---|---|---|
| Figma для компьютера, не браузер | [figma.com/downloads](https://www.figma.com/downloads/) | в меню Plugins есть пункт Development |
| Claude Code | [claude.com/claude-code](https://claude.com/claude-code) | в терминале работает команда `claude` |
| Node.js, версия LTS | [nodejs.org](https://nodejs.org/) | `node -v` в терминале показывает версию |
| Python 3 | на Mac обычно уже есть; если нет — [python.org](https://www.python.org/downloads/) | `python3 --version` |

## 2. Установка (около 3 минут, один раз)

**Шаг 1. Попросите Claude установить.** Откройте Claude Code и отправьте:

> Установи фигма-мост: https://github.com/Rreerreea/claude-figma-bridge

Claude все скачает, запустит мост и откроет в Finder папку **Документы → Claude Bridge**.

То же самое можно сделать одной строкой в Терминале:

```
curl -fsSL https://raw.githubusercontent.com/Rreerreea/claude-figma-bridge/main/install.sh | bash
```

**Шаг 2. Добавьте плагин в Figma.**

1. Откройте любой файл в приложении Figma.
2. Меню **Plugins → Development → Import plugin from manifest…**
3. Слева выберите **Документы → Claude Bridge → manifest.json** и нажмите **Open**.

В меню Plugins → Development появится **Claude Bridge**.

**Шаг 3. Перезапустите Claude Code**, чтобы он увидел новый навык.

**Шаг 4. Проверьте.** Запустите в Figma Plugins → Development → **Claude Bridge**. В маленьком окне должно появиться
«Connected to Claude ✓» и название файла. Напишите Claude «проверь мост»: он ответит, к какому файлу подключен.

Готово. Больше это делать не нужно.

---

## 3. Первый раз: пробуем за 5 минут

**1. Откройте папку проекта в Claude Code.** Claude хранит в ней файл задач и правила проекта, поэтому для каждого
проекта лучше своя папка, например «Документы/Сайт клиента». В Терминале:

```
cd ~/Documents/"Сайт клиента"
claude
```

В приложении Claude Code просто выберите эту папку.

**2. Откройте файл в Figma и запустите плагин:** Plugins → Development → **Claude Bridge**. Быстрее так: **Cmd + /**,
напечатайте «Claude Bridge», Enter. В маленьком окне плагина будет:

- «Connected to Claude ✓» — связь есть;
- «File: …» — название файла, в котором он запущен;
- пока Claude работает — «Running job #…», потом «Jobs done: …».

Окно не закрывайте, его можно отодвинуть в угол. Закроете окно — Claude потеряет доступ к файлу.

**3. Проверьте связь.** Напишите Claude:

> Проверь фигма-мост

Он ответит, к какому файлу подключен. Если пишет, что не подключен, запустите плагин еще раз именно в этом файле.

**4. Дайте безопасную задачу на чтение.** Она ничего не меняет, зато видно, что Claude «видит» файл. Выделите в Figma
любой фрейм и напишите:

> Посмотри выделенное и расскажи, как оно устроено

Claude опишет слои, автолейаут, стили и может показать картинку фрейма.

**5. Сделайте первую маленькую правку.** Например:

> Поменяй в выделенном фрейме текст кнопки на «Оформить заказ»

Claude поменяет текст, проверит результат по картинке и коротко отчитается. Посмотрите в Figma: правка уже там.

**6. Попробуйте откатить:** Cmd + Z в Figma или напишите Claude «верни как было». Теперь вы знаете весь цикл.

---

## 4. Обычный рабочий день

1. Откройте Claude Code в папке проекта.
2. Откройте файл в Figma и запустите Claude Bridge.
3. Если работа продолжается с прошлого раза, напишите: «Продолжаем, прочитай файл задач». Claude вспомнит, что
   сделано и что ждет ответа.
4. Ставьте задачи по одной: задача, отчет, проверка, следующая задача.

После перезагрузки компьютера сервер моста выключается. Claude запустит его сам, когда понадобится. Если в окне плагина
видите «No connection», напишите Claude «подключи фигма-мост».

---

## 5. Как ставить задачи

Говорите как с коллегой-дизайнером. Хорошая задача отвечает на четыре вопроса:

1. **Где.** Ссылка на фрейм или слой, выделение в Figma или скрин.
2. **Что должно получиться.** Описывайте результат, а не способ: «кнопка на всю ширину», «между карточками 24».
3. **Чего не трогать.** «Остальное не меняй», «главную не трогай», «правки заказчика оставь как есть».
4. **Откуда факты.** «Цены бери с сайта …», «тексты из этого документа». Без этого Claude поставит пример и предупредит
   об этом.

### Как показать место

- **Ссылка.** Выделите фрейм или слой → **Cmd + L** (или правой кнопкой → Copy/Paste as → Copy link to selection) →
  вставьте ссылку в чат. Это самый точный способ.
- **Выделение.** Выделите слой в Figma и напишите «посмотри выделенное».
- **Скрин.** Вставьте картинку в чат Claude Code (Ctrl + V или перетащите). Удобно для комментариев заказчика и для
  примеров «хочу как здесь».

### Примеры задач

- **Правка:** «Вот фрейм (ссылка). Сделай заголовок короче: „Корзина“, а количество позиций — серым рядом».
- **Разбор:** «Посмотри этот экран (ссылка) и скажи, что кривого: отступы, выравнивание, тексты. Пока ничего не меняй».
- **Комментарии заказчика:** «Пойдем по комментариям» — и присылайте скрины комментов по одному. Claude объяснит, что
  имел в виду заказчик, сделает правку и коротко отчитается. Если коммент непонятный, спросите «что он значит?»: Claude
  объяснит и ничего не будет менять, пока вы не скажете «давай».
- **Состояния:** «Собери состояния поля промокода: ввод, проверка, ошибка, применен». Claude положит их рядом с экраном.
- **Массовые правки:** «Скругли углы всех плашек на 20 во всех макетах», «Найди дробные размеры и округли».
- **Компоненты:** «Поставь в карточку счетчик из дизайн-системы вместо текста „2 шт“».
- **Сначала план:** «Хочу добавить в оформление выбор времени доставки. Сначала скажи, как сделаешь».

Большие задачи дробите на шаги и проверяйте после каждого. Так проще поймать ошибку, пока она маленькая.

## 6. Что Claude делает сам и о чем спросит

Сам:

- сначала смотрит, как устроен макет, и только потом правит;
- работает внутри вашей структуры: те же блоки, компоненты, стили и переменные;
- после правки выгружает картинку и проверяет ее;
- перед большими правками сохраняет версию в истории файла и пишет ее название;
- в отчете пишет, что поменял, что сознательно не трогал и какие значения взяты для примера.

Спросит, если:

- задачу можно понять двумя способами;
- правка заденет другие экраны или компоненты дизайн-системы;
- нужно что-то удалить или поменять то, что правил заказчик.

Пока Claude работает, лучше не править тот же фрейм и не жать Cmd + Z: так можно отменить и его правку.

---

## 7. Как откатить

- **Сразу после правки:** Cmd + Z в Figma. Учтите: так же можно случайно отменить правку Claude, которую вы хотели
  оставить.
- **Большую правку:** File → **Show version history**. Найдите версию, которую сохранил Claude (например, «До скосов …»),
  и восстановите ее.
- Или просто напишите Claude: «верни как было в этом фрейме».

---

## 8. Правила проекта и файл задач

**Правила.** У каждого проекта есть договоренности, которые Claude не угадает: откуда брать цены, какой шаг отступов,
какие фирменные формы, что нельзя трогать. Положите их в папку проекта файлом `PROJECT-RULES.md` и скажите Claude:
«читай правила проекта». Пример такого файла:
[project-rules-example.md](plugins/figma-bridge/skills/figma-bridge/references/project-rules-example.md).

**Файл задач.** Claude ведет в папке проекта список: что сделано, с номерами фреймов, и что ждет вашего ответа. В новом
чате скажите «продолжаем, прочитай файл задач», и не придется объяснять все заново.

## 9. Если что-то не работает

| Что видите | Что сделать |
|---|---|
| В окне плагина «No connection — is the bridge server running?» | Напишите Claude «подключи фигма-мост» |
| Claude пишет, что плагин не подключен | Запустите Claude Bridge именно в том файле, который правите |
| Плагин открыт в нескольких файлах | Закройте его везде, кроме нужного файла. Задачи и так уходят только в файл с нужным названием, но лучше не рисковать чужими файлами |
| «Unable to establish connection to Figma» | Так бывает после сна компьютера. Закройте окно плагина и запустите его снова |
| В меню Plugins нет пункта Development | Вы в браузере. Нужно приложение Figma для компьютера |
| Claude «не видит» комментарии | Так и есть: плагинам комментарии недоступны. Присылайте скрины |
| Правка пропала | Кто-то нажал Cmd + Z. Попросите Claude проверить и сделать снова |
| Переименовали файл | Перезапустите плагин и скажите Claude новое название |

---

## 10. Безопасно ли это

- Сам мост работает только на вашем компьютере и в интернет ничего не отправляет. А вот слои и картинки, которые Claude
  читает из файла, попадают к Claude, как любое сообщение в чате. Не открывайте ему файлы, которые нельзя показывать.
- Сервер принимает задачи только с секретным ключом, который создается при каждом запуске.
- Плагин может менять открытый файл, на то он и нужен. Поэтому запускайте его только в файлах, которые разрешаете
  править.
